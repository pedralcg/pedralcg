## Proyectos destacados

### [Geoportal Ambiental — Región de Murcia](https://github.com/pedralcg/geoportal-rm)
Aplicación web para consultar y analizar capas ambientales de la Región de Murcia. Espacios protegidos, usos del suelo e hidrología en tiempo real desde servicios WMS oficiales.
`JavaScript` `OpenLayers` `WMS/WMTS` `GeoJSON` `Supabase`

### [Visor Comparativo de Cartografía Histórica](https://github.com/pedralcg/visor-comparador-ol)
Deslizador interactivo para comparar cartografía histórica y actual sobre el mismo encuadre. Permite cargar capas propias, dibujar y medir.
`JavaScript` `OpenLayers` `WMS/WMTS` `GeoJSON`

### [Mapa Etnoturístico — Ruta de las Fundiciones](https://github.com/pedralcg/visor-ruta-etnografica-leaflet/)
Mapa interactivo para explorar el patrimonio industrial y etnográfico de la Ruta de las Fundiciones en La Unión, Murcia.
`JavaScript` `Leaflet` `GeoJSON`
